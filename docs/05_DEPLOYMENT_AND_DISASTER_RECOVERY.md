## 2. 상태 확인

- Liveness: 프로세스가 응답하는지 `/health`로 확인
- Readiness: DB·Redis·필수 설정이 준비되었는지 `/ready`로 확인
- 배포 성공 조건: 컨테이너 실행, readiness 통과, 핵심 API 통합 테스트 통과
- 시크릿: 카카오 키·DB URL·토큰·PG 키는 환경 변수와 CI Secret에서만 주입

## 3. 장애 유형과 복구 정책

| 유형 | 감지 조건 | 복구 전략 | 최종 실패 처리 |
| --- | --- | --- | --- |
| 지도/장소 API | timeout 또는 5xx 연속 | 2회 재시도 → 캐시 폴백 | 지도 제한 안내·관리자 알림 |
| DB | 연결 실패/느린 쿼리 | 연결 재생성 → 읽기 캐시 | 읽기 전용 안내 |
| 예약 연동 (P1) | 5xx/응답 없음 | 1회 재시도 → 문의 접수/외부 링크 | 예약 불가 안내 |
| 결제 웹훅 (P1) | 서명 실패/지연/중복 | 검증·상태 재조회·큐 재처리 | PAST_DUE 유예·운영자 안내 |
| Instagram 임베드 (P1) | 비공개/삭제/oEmbed 오류 | 계정 링크 폴백 | 최근 소식 미표시 안내 |
| 장애 제보 알림 | 알림 전송 실패/담당자 미지정 | 재시도·조직 관리자 대체 알림 | 대시보드 미처리 경고 |
| Agent | 비정상 종료/형식 불일치 | 상태 복원·대체 경로·재요청 | 안전한 오류 응답 |
| 프롬프트 공격 | 시크릿·권한 상승 요구 | 요청 차단·보안 로그 | 관리자 알림 |
| 조직 권한 침범 | 타 조직/지점 데이터 요청 | 서버 권한 검사·403 응답·감사 로그 | 보안 알림 |
| 자동 승인 규칙 | 규칙 평가 실패/중복 후보 오류 | PENDING_REVIEW로 안전 전환·관리자 알림 | 자동 공개 보류 |
