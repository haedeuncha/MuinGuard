# MuinGuard 프로젝트 개요

## 1. 서비스 정의

MuinGuard는 사용자의 현재 위치 또는 검색 지역을 기준으로 주변의 무인호텔·무인모텔·비대면 체크인 숙소와 무인편의점·카페·세탁소·사진관·스터디카페 등을 탐색하게 하는 위치 기반 통합 정보 서비스다.

사용자는 지도, 거리, 운영시간, 주차, 전화번호, 편의시설을 확인한다. 운영자는 장소 정보를 관리하고 시설 장애 제보 관리와 다점포 통합 현황을 사용한다. 예약 문의·AI 운영 리포트·테스트 구독 결제는 P1 확장 범위다.

## 2. 목표

- 실제 서비스 수준의 반응형 웹 화면을 구현한다.
- 카카오맵을 활용해 현재 위치 주변 장소를 지도와 목록으로 제공한다.
- 회원·운영자·관리자 권한을 분리한다.
- 지도·장소·시설 제보 알림·Agent 장애를 자동 감지하고 복구한다.
- Supervisor 기반 멀티 에이전트 협업과 Handoff 이력을 시연한다.

## 3. 역할

| 역할 | 핵심 기능 |
| --- | --- |
| 비회원 | 지도 탐색, 장소 상세 조회 |
| 일반 회원 | 즐겨찾기, 리뷰, 시설 장애 제보 |
| 운영자(사장) | 직접 장소 등록/수정, 사업자 인증 제출, 시설 제보 처리, 다점포 현황 확인 |
| 관리자 | 자동 승인 예외 검토, 신고 처리, 승인 정책·장애·복구 로그 확인 |

## 4. 단계별 범위

### P0 — 발표 전 반드시 완성

1. 현 위치/지역 기반 지도 검색과 카테고리·조건 필터
2. 장소 상세: 사진, 주소, 전화번호, 운영시간, 시설, 지도, 길찾기, 인증 Instagram 프로필 링크
3. 회원가입·로그인, 즐겨찾기, 리뷰
4. 사장 직접 장소 등록과 규칙 기반 자동 승인·관리자 예외 검토
5. 시설 장애 제보 접수·우선순위 분류·운영자 알림
6. 여러 매장을 하나의 사업자 조직으로 묶는 다점포 통합 관리
7. 지도 API·DB·Agent·알림 장애의 자동 복구

### P1 — P0 안정화 후 확장

- 무인숙소 예약 문의 및 외부 예약 링크
- AI 제보 요약·유사 장애 묶기·운영 리포트
- 공개 Instagram 게시물·Reel의 공식 임베드
- Basic/Pro/Business 권한과 테스트 구독 결제 흐름
- 상단 노출, 이벤트 등록, 상세 유입 통계

### P2 — 실제 사업 검증 후 확장

- 실제 정기결제, 실시간 객실 재고, 확정 예약, 정산·환불

## 5. 비범위

- 실제 숙박 객실 재고 동기화와 실결제는 P2 확장 기능으로 둔다.
- 실제 결제 카드 정보를 직접 저장하지 않는다.
- 수집 근거가 없는 매장·숙소 정보는 등록하지 않는다.

## 6. 95점 목표 품질 기준

아래는 구현 전 목표값이다. 발표·보고서에는 반드시 실제 측정값을 함께 기록한다.

| 영역 | 목표 기준 | 증빙 |
| --- | --- | --- |
| 핵심 사용자 흐름 | 검색 → 상세 → 문의/제보가 배포 환경에서 완주 | 시연 영상·통합 테스트 |
| 정보 신뢰성 | 장소마다 정보 출처·최종 확인 시각·검증 상태 제공 | 상세 화면·DB 기록 |
| 장애 복구 | 최소 4개 장애 시나리오, 자동 복구율 목표 80% 이상 | recovery log·측정표 |
| 복구 시간 | 지도 API 폴백 목표 10초 이내, 알림 폴백 목표 60초 이내 | 타임스탬프 로그 |
| 보안 | 역할·조직별 데이터 격리, 시크릿 미노출 | 권한 테스트·저장소 점검 |
| 배포 품질 | 테스트 실패 시 배포 차단, readiness 확인 실패 시 롤백/이전 버전 유지 | CI 실행 결과 |
| 발표 안정성 | 라이브 시연과 백업 영상·고정 테스트 데이터 준비 | 발표 체크리스트 |
