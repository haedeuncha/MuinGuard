# MuinGuard 시험 및 시연 계획서

## 1. 시험 원칙

- 정상 기능뿐 아니라 장애와 자동 복구를 같은 수준으로 검증한다.
- 시험 결과는 입력, 기대 결과, 실제 결과, 복구 시간, 수동 개입, 증빙을 남긴다.
- 발표에는 실제 실행 로그와 화면 캡처를 사용한다.

| ID | 장애 주입 | 기대 복구 | 확인 지표 |

## 4. 20분 발표 시연 순서

1. **문제와 서비스 소개 (2분):** 무인 운영 공간 정보를 한 곳에서 찾기 어려운 문제와 MuinGuard 소개
2. **실제 서비스 화면 (4분):** 현 위치 기반 검색, 카카오맵, 상세 정보, 로그인/찜
3. **운영자 수익 모델 (2분):** P0 다점포·시설 제보 가치와 P1 Pro 구독 확장 계획
4. **멀티 에이전트 구조 (3분):** Agent 역할, Handoff, 공유 상태 설명
5. **정상 요청 시연 (3분):** 주변 무인숙소 검색 → Info → Critic PASS → 응답
6. **장애 주입·복구 시연 (4분):** 지도 API timeout 또는 Agent 종료 → 재시도·캐시 폴백·로그 확인
7. **배포·CI/CD·결과 (2분):** Pipeline, 테스트 차단, 복구 지표, 개선 계획

## 5. 발표 전 체크리스트

- [ ] 배포 URL, 저장소 URL, 모니터링/로그 URL 준비
- [ ] 카카오맵 키와 배포 도메인 정상 등록 확인
- [ ] 장애 주입 환경은 운영 환경과 분리
- [ ] 테스트 계정과 샘플 장소 데이터 준비
- [ ] 네트워크 오류에 대비한 시연 영상 준비
- [ ] 실제 복구 시간·성공률·실패 사례 기록
- [ ] 모든 발표 수치는 목표값이 아닌 실제 측정값인지 확인
