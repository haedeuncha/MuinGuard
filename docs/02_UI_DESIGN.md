# MuinGuard 화면 설계서

## 1. 디자인 원칙

- 모바일 우선 반응형 UI
- 지도와 장소 정보를 한 화면에서 빠르게 비교
- 예약 확정과 예약 문의를 명확히 구분
- 실제 서비스 수준의 일관된 네비게이션·로딩·오류 상태 제공
- 기존 서비스의 로고·상표·화면을 그대로 복제하지 않고 자체 디자인 사용

## 2. 공통 레이아웃

```text
[로고] [주변 찾기] [무인숙소] [무인샵] [매장 등록]     [로그인/프로필]
-----------------------------------------------------------------------
                           페이지 콘텐츠
-----------------------------------------------------------------------
[모바일 하단 탭: 홈 | 지도 | 찜 | 마이]
```

## 3. 화면별 명세

| 화면 | 경로 | 주요 구성 |
| --- | --- | --- |
| 홈 | `/` | 위치 권한, 검색창, 카테고리, 추천 장소 |
| 주변 지도 | `/map` | 필터·장소 카드 목록·카카오맵·현재 위치 마커 |
| 장소 상세 | `/places/{placeId}` | 사진, 평점, 전화, 운영시간, 시설, 지도, 길찾기 (예약/문의는 P1) |
| 로그인/가입 | `/login`, `/signup` | 이메일·비밀번호·유효성 검증·약관 |
| 마이페이지 | `/mypage` | P0: 즐겨찾기·리뷰 / P1: 예약 문의 내역 |
| 운영자 센터 | `/owner` | P0: 장소 등록·승인 상태·시설 장애 제보·지점 현황 / P1: 예약 문의·AI 리포트·구독 관리 |
| 다점포 관리 | `/owner/organization` | 지점 선택, 전체 현황, 담당자·권한 관리 |
| 관리자 | `/admin` | 장소 승인, 신고, 장애·복구 로그 |

### 사장 장소 등록·승인 화면

```text
기본 정보 → 위치·운영시간 → 사진·이용 안내 → 사업자 인증 → 제출
                                                     ↓
                       조건 충족: 자동 승인·공개 / 예외: 관리자 검토 대기
```

- 사장은 운영자 센터에서 등록 상태와 누락 조건을 확인한다.
- 자동 승인된 장소에는 `운영자 인증` 배지를 표시한다.
- 검토 대기 상태에는 누락 정보·중복 후보·검토 진행 상태를 표시한다.
- 관리자는 예외 건에서 승인/반려와 사유 입력만 수행한다.

### 주변 지도 화면

```text
+--------------------------+-----------------------------------+
| [검색] [필터]            |                                   |
| 현재 위치 반경 3km        |             카카오맵              |
| 장소 카드 목록            |   현 위치 마커 + 장소 마커         |
| - 이미지/이름/거리/평점   |                                   |
| - 운영 여부/주차/24시간   |                                   |
+--------------------------+-----------------------------------+
```

데스크톱에서는 목록/지도를 40:60으로, 모바일에서는 지도 위 하단 시트에 목록을 표시한다. 지도 오류 시 주소·목록은 유지하며 오류 안내를 표시한다.

### 장소 상세 화면 필수 정보

```text
장소명 / 카테고리 / 평점 / 찜 / 운영자 인증 배지
주소 / 전화번호 / 운영시간
주차·24시간·키오스크·반려동물 등 편의시설
카카오맵 위치 / 길찾기
숙소: 체크인 방식·체크아웃 시간
P0 버튼: 전화하기 / 즐겨찾기 / 길찾기 / 시설 문제 제보
P1 버튼: 예약 문의 / 외부 예약 이동
```

장소 정보 아래에 `정보 출처`, `최종 확인일`, `운영자 인증 여부`를 표시한다. 정보가 오래되었거나 미확인일 경우 이를 숨기지 않고 사용자에게 알린다.

### 트렌드형 신뢰·소셜 영역

- **P0 `오늘의 이용 정보`:** 24시간 여부, 주차, 체크인 방식, 최종 확인일을 한 줄 신뢰 카드로 표시한다.
- **P0 `공식 Instagram`:** 운영자 인증 배지와 `@계정명` 외부 이동 버튼만 제공한다.
- **P1 `최근 소식`:** 운영자가 선택한 공개 Instagram 게시물·Reel을 공식 임베드로 최대 3개 표시한다.
- 공개 게시물 임베드가 실패하거나 계정이 비공개면 빈 영역 대신 `Instagram에서 보기` 링크만 제공한다.
- 트렌드 태그는 근거 있는 데이터만 사용한다. 예: `24시간`, `무인 체크인`, `주차 가능`, `최근 정보 확인`.

### P1 구독 화면

- Basic/Pro/Business 비교와 구독 버튼
- 현재 요금제, 다음 결제일, 결제 내역, 결제수단 변경, 해지 예약
- Pro 권한: AI 운영 리포트, 시설 장애 제보 관리, 상단 노출, 통계, 이벤트 등록
- Business 권한: 여러 지점 통합 현황, 지점별 비교, 팀원 초대와 역할 관리

### 시설 장애 제보 관리 화면

- 고객 제보: `키오스크`, `결제`, `출입문`, `청결`, `재고`, `기타` 선택과 사진·설명 입력
- 운영자 목록: 제보 시간, 지점, 심각도, 분류, 현재 상태, 담당자 표시
- P0 상세: 원본 제보, 처리 메모, 상태 변경 이력
- P1 상세: AI 요약, 유사 제보 수
- 심각도 높은 제보는 운영자 대시보드 상단과 알림 영역에 표시

### 다점포 통합 관리 화면

```text
[전체 지점] [강남점] [홍대점] [성수점]
이번 주 조회·전화·예약 문의·미처리 장애 제보
지점별 비교 차트 / 최근 제보 / 담당자별 처리 현황
```

- 조직 관리자는 지점 관리자와 조회 전용 직원을 초대한다.
- 장소별이 아닌 조직 단위로 Pro/Business 권한을 확인한다.

### 고득점 UX 보완

- 검색·상세·제보의 핵심 동작을 모바일과 데스크톱에서 모두 검증한다.
- 지도 로딩 실패, 정보 미확인, 예약 연동 실패를 각각 별도 상태 화면으로 제공한다.
- 모든 중요한 버튼에는 로딩·성공·실패 피드백을 제공한다.
- 접근성: 키보드 이동, 레이블, 색상 대비, 이미지 대체 텍스트를 점검한다.

## 4. 상태·접근성

| 상태 | 처리 |
| --- | --- |
| 로딩 | 스켈레톤 카드와 지도 로딩 인디케이터 |
| 결과 없음 | 조건 완화 버튼과 장소 제보 유도 |
| 위치 거부 | 지역명 검색과 기본 지역 제공 |
| 지도 오류 | 목록·주소 유지, 캐시 기준 안내 |
| 예약 API 오류 (P1) | 예약 문의 또는 외부 예약 링크 제공 |
| 결제 실패 | 결제 미완료·재시도·구독 유예 안내 |

버튼·입력창 레이블, 키보드 이동, 이미지 대체 텍스트, 충분한 색상 대비를 적용한다.
